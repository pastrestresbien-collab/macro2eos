## Notes préliminaires (texte officiel)

Pour activer les fonctions Eos sur les touches Fonction de macOS :
- Ouvrir Préférences Système (Systems Preferences)
- Aller dans la section Clavier (Keyboard)
- Activer le réglage « Use all F1, F2, etc... keys as standard function keys »

> **Note** : certains claviers internationaux nécessitent de désactiver « Use Shift Key as Eos Shift » dans la section General des réglages de l'ECU. Dans ces cas, utiliser **Z** comme Shift pour accéder aux fonctions de raccourci.
