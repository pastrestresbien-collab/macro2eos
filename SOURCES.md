# Sources officielles des manuels ETC Eos

URLs vérifiées (recherche web du 2026-07-30). Tous ces documents sont des
publications officielles ETC, hébergées sur etcconnect.com ou sur des miroirs
qui redistribuent les PDF officiels à l'identique.

> **Note d'environnement** : la politique réseau de la session Claude Code
> ayant préparé ce dépôt n'autorisait que GitHub et les registres de paquets ;
> les téléchargements directs depuis etcconnect.com et ses miroirs étaient
> bloqués. Pour lancer la conversion : soit élargir la politique réseau de
> l'environnement (autoriser `www.etcconnect.com`, `media.musson.com`), soit
> déposer les PDF dans `manuals/<document>/source/` et pousser sur la branche.

## 1. Eos Family Operations Manual

Depuis la v3.0, le manuel s'appelle simplement « Eos Family Manual » et la
référence courante est l'aide en ligne WebDocs.

- Aide en ligne (version courante, v3.3.6) :
  https://www.etcconnect.com/WebDocs/Controls/EosFamilyOnlineHelp/en/
- Page de documentation officielle (PDF les plus récents) :
  https://www.etcconnect.com/Products/Legacy/Console/Eos-Family/Eos/Documentation.aspx
- PDF v2.9.1 (dernier de la lignée 2.x, couvre les chapitres demandés — Patch,
  Setup, Effects, Macros, Show Control) — miroir :
  https://www.10kused.com/wp-content/uploads/2017/11/EosFamily_v2.9.1_OperationsManual_RevA.pdf
- PDF v3.0.0 — miroir :
  https://earlgirlsinc.com/files/2023/02/EosFamily_v3.0.0_OperationsManual_RevA_compressed_(1).pdf
